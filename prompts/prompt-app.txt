Create a complete, single-page portfolio website for an experienced professional developer using React. The portfolio must strictly follow the design system specified in design.json.
Required Sections (in order):

1. Hero Section

Full viewport height with dark navy gradient background
Left side: Large bold heading with "Hello." + name, title "Software Developer" or similar
Two CTAs: Primary coral button ("Get a project") and secondary outlined button ("My resume")
Technology icons row below (HTML, CSS, JavaScript, Node.js, React, Git, GitHub) in muted gray
Right side: Professional photo in circular frame with radial coral-to-orange gradient background
Decorative angular bracket elements around the photo
Fixed/absolute navigation bar with Home, About, Projects, Contacts links

2. About Me Section

Left sidebar with three service offerings (icons + text):

Website Development
App Development
Website Hosting


Each with icon and connected by vertical coral accent line
Right side: "About me" heading + personal narrative paragraph
Three stat cards in a row below the text:

"120+ Completed Projects"
"95% Client satisfaction"
"10+ Years of experience"


Numbers in large coral text, labels in muted gray below

3. Projects Section

Section heading: "Projects" centered with small decorative underline
3-4 project cards with alternating layouts:

Project Name as card heading
Technology tags (HTML, CSS, JavaScript, etc.) as small pills
Brief description of the project
Left or right: Screenshot, code snippet, or mockup image
Two buttons: Coral "View GitHub" and ghost "View project →"


Projects should include variety: game (Battleship), API integration (Movie Titles API), tool (Calculator), and landing page (SaaS)

4. Contact Section

Dark background with subtle texture or pattern
Left side: Large heading "Have a project? Let's talk!"
Right side: Contact form with three fields:

Name input
Email input
Message textarea


Coral "Submit" button
Footer below with name, copyright text, and social icons (Twitter, GitHub, LinkedIn)
